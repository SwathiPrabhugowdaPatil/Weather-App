# Weather App

A simple and responsive weather app that shows current weather details for a searched city. The app displays key information such as temperature, weather condition, humidity, and wind speed in a clean card-style layout.

## Features

- Search weather by city name.
- Displays current temperature.
- Shows weather condition such as Clouds, Rain, Clear, etc.
- Shows humidity percentage.
- Shows wind speed.
- Clean and minimal user interface.
- Mobile-friendly and easy to use.

## Preview

The app interface includes:

- City name
- Date
- Temperature
- Weather condition
- Humidity
- Wind speed
- City search input and search button

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## How It Works

1. Enter the name of a city in the search field.
2. Click the search button.
3. The app fetches and displays the current weather details for that city.
4. Weather information updates dynamically based on the searched location.


## Usage

- Open the app in a browser.
- Type a city name.
- Click **Search City**.
- View the weather results instantly.
